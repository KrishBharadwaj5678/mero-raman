## <img src="https://github.com/KrishBharadwaj5678/mero-raman/raw/main/readme/gifs/gettingStarted.gif" width="35"/> はじめ方

### 1️⃣ リポジトリをクローンする

```bash
git clone https://github.com/KrishBharadwaj5678/mero-raman.git
````

### 2️⃣ プロジェクトディレクトリへ移動する

```bash
cd mero-raman
```

### 3️⃣ 依存関係をインストールする

```bash
npm install
```

### 4️⃣ 開発サーバーを起動する

```bash
npm run dev
```

### 5️⃣ ブラウザでアプリを開く
