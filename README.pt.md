## <img src="https://github.com/KrishBharadwaj5678/mero-raman/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Como Começar

### 1️⃣ Clone o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/mero-raman.git
````

### 2️⃣ Acesse o Diretório do Projeto

```bash
cd mero-raman
```

### 3️⃣ Instale as Dependências

```bash
npm install
```

### 4️⃣ Inicie o Servidor de Desenvolvimento

```bash
npm run dev
```

### 5️⃣ Abra o Aplicativo no Navegador
