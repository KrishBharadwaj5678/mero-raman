## <img src="https://github.com/KrishBharadwaj5678/mero-raman/raw/main/readme/gifs/features.gif" width="35"/> Features

| Feature | Description |
| -------------------------- | ------------------------------------------------------------- |
| 🕉️ Spiritual Articles | Explore devotional articles, spiritual teachings, and stories of divine love |
| 🛕 Darshan Timings | Find temple darshan schedules and daily worship timings |
| 🖼️ Divine Gallery | View beautiful images and divine moments of Shri Radha Raman Ji |
| 🗺️ Temple Location | Easily find Shri Radha Raman Ji Temple's location with map integration |
| 🎨 Modern UI | Modern, elegant UI with smooth animations and easy navigation |
| 📱 Responsive Design | Enjoy a seamless devotional experience on desktop, tablet, and mobile devices |

## <img src="https://github.com/KrishBharadwaj5678/mero-raman/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/mero-raman.git
```

### 2️⃣ Navigate to the Project

```bash
cd mero-raman
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start the Development Server

```bash
npm run dev
```
