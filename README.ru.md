## <img src="https://github.com/KrishBharadwaj5678/mero-raman/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/mero-raman.git
````

### 2️⃣ Переход в каталог проекта

```bash
cd mero-raman
```

### 3️⃣ Установка зависимостей

```bash
npm install
```

### 4️⃣ Запуск сервера разработки

```bash
npm run dev
```
